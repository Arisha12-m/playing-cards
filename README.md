# playing-cards
Playing Cards layout built with HTML and CSS Flexbox as part of the freeCodeCamp CSS Flexbox curriculum.
Overview

Three playing cards (Ace of Spades, King of Hearts, Queen of Diamonds) are laid out using Flexbox, with each card's rank/suit positioned at the top-left, center, and bottom-right using justify-content and align-self.

# How to View

Open index.html in any web browser — no setup required. styles.css is linked automatically.
